# Muffin Formula

Same-day sourdough English muffin calculator. Static files only: no build step.

## Host on GitHub Pages
1. Create a new public repository (for example `muffin-formula`) and upload everything in this folder, keeping the `icons` folder.
2. In the repository, open Settings, then Pages. Under Build and deployment, choose Deploy from a branch, pick `main` and `/ (root)`, and save.
3. After a minute the site is at `https://YOUR-USERNAME.github.io/muffin-formula/`.

## Put it on an iPhone
Open that address in Safari, tap Share, then Add to Home Screen. It opens full screen with the muffin icon and works offline after the first load.
